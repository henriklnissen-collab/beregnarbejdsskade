# docs/

**prototype.html** er den klikbare prototype. Åbn den i en browser.
Den er facit for, hvordan flowet og designet skal se ud.
Al HTML, CSS og tekst kan genbruges direkte.

Rækkefølgen i prototypen:
forside → CVR-opslag → bekræft årsværk → pris → vælg modtagere →
kontakt → samtykke → overblik → vælg selskab → selskabets svarside

Satserne i prototypen og i lib/priser.ts er de samme gæt.
Ret begge steder, når I får rigtige tal.
